# Quickstart: Multi-Monitor

1. Connect a second display (or use existing).
2. Open Meeting Recorder → fuente: verify Pantalla 1 / Pantalla 2 entries.
3. Select Pantalla 2 → preview should show that display.
4. Record 3–5 s → open MP4 → content is monitor 2.
5. Actualizar fuentes → selection preserved if monitor still present.
6. Single-monitor machine: one Pantalla entry; window list still works.
